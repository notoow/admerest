# admerest

전문의별 총 수술 케이스를 중심으로, 진피 누적 길이를 탑과 랜드마크로 함께 둘러보는 반응형 3D 프로토타입.

실행 사이트: https://notoow.github.io/admerest/

## 배포

`main`에 push하면 `.github/workflows/pages.yml`이 JavaScript와 모델 파일을 검사하고 `dist/`를 GitHub Pages에 자동 배포합니다. 모든 에셋 경로는 `/admerest/` 하위에서도 동작합니다. 이전 Sites 배포는 별도이며 이후 자동 갱신하지 않습니다.

## 실행

`npm run dev` 실행 후 http://127.0.0.1:5173 열기. 정적 파일은 `dist/`에 있으며 빌드 단계 없이 정적 호스팅할 수 있습니다. Three.js, Rapier 및 국가 깃발은 로컬에 포함되어 있습니다.

## 구현

- 한 장 → 도시 → 에베레스트로 이어지는 3단계 스크롤 연출, 실제 ADM 모델과 Imagegen 설산 배경
- 전체 화면 보행: 지면 위 1.7m 눈높이, WASD 이동, 기본 속도 약 2.6배 개선, 마우스 자유 시점
- Q 상승 시 비행 전환, E 하강, Shift 가속, 보행 버튼으로 지면 복귀, Esc 마우스 해제 후 다시 Esc로 종료
- 모바일 왼쪽 아날로그 조이스틱 + 오른쪽 터치 시점, 독립 멀티터치, 상승/하강/가속 버튼
- 도시/에베레스트 산기슭/내 체험 탑 빠른 이동, 이동 속도 조절
- 고도 표시, 대기 원근·하늘·구름·주변 지형을 포함하는 탐색 공간
- 총 수술 케이스가 메인, 진피 길이가 보조인 히어로·합계·전문의 카드·3D 라벨·랭킹
- 수술 건수에 따라 정렬한 랭킹, 국적 필터와 별도 길이 기록
- 전문의별 탑 선택, 카메라 이동, 회전·확대, 자동 회전
- 전문의/내 체험 탑과 랜드마크를 같은 기준선·높이 비율로 나란히 비교, 높이 차이와 비율 실시간 표시
- 탑 화면 안에서 체험 수술 건수 입력·추가·초기화·규격 전환, 아래쪽을 유지하며 위로 자라는 대표 시트
- Sketchfab 공개 모델: 롯데월드타워 555m, 부르즈 칼리파 828m, 상하이타워 632m, 에펠탑 330m. 에베레스트 8,848.86m 비교도 유지
- 제작자 모델의 창문·정상부·철골 보존, 환경 반사, 4개 GLB 합계 약 1.64 MiB. 원본 형상 축소 없이 Draco 압축, 공통 바닥·높이 정규화, 로딩 실패 시 대체 모형
- +10/+100/+500/+1,000, 직접 입력, 초기화, 5×6/5×8/5×10/6×12cm 규격 전환
- 사진 기반 ADM 표면과 옆면, 실제 관통 구멍 및 절개 형상
- 사용자 확인 규격 **5×6cm, 두께 3mm**를 적용한 Blender 모델
- 사진에서 추출한 원형 구멍 12개와 절개 83개, 미세한 휘어짐, 섬유 질감의 표면과 절단면
- 정면·사선·뒷면·3mm 옆면 시점, 드래그 회전·확대
- 확대용 81,396개 / 낙하용 12,824개 삼각형 모델, 공유 텍스처와 Draco 압축 GLB
- Rapier 중력·충돌·마찰을 적용한 대표 시트 낙하, 최대 48개 물체로 제한
- 국적 필터, 파란 인증 배지의 hover/focus/tap 설명, 랭킹에서 탑 이동
- WebMCP: 상태 조회, 체험 수량·규격 변경, 전문의 선택, 랜드마크 선택

## 데이터와 표현 범위

공개 전문의 이름, 국적, 인증 상태, 사용 기록은 모두 가상 예시입니다. 실제 회원가입·본인확인·CRM 연결·자격증 심사·서버 기록 저장은 연결하지 않았습니다. 새로고침하면 메인 체험 수량은 초기값으로 돌아옵니다. 체험 조작은 랭킹에 반영되지 않습니다. `record.html`에서 명시적으로 저장한 개인 초안만 같은 브라우저에서 복원됩니다.

보행은 지면 위 1.7m를 유지하며 산의 표면 높이를 따라갑니다. 랜드마크의 단순화한 바닥 영역에는 수평 충돌 제한을 적용합니다. 시야각과 무관하게 WASD는 수평 이동하고 Q/E는 수직 이동합니다. 넓은 공간의 탐색을 위해 이동 속도는 실제 사람의 걸음 속도보다 빠르게 설정했습니다.

PC는 클릭 시 브라우저의 Pointer Lock을 요청하며 마우스 이동만으로 시점을 바꿉니다. 이를 지원하지 않는 내장 브라우저에서는 캔버스에 포커스가 있는 동안 드래그 없이 마우스 이동으로 시점을 바꾸는 대체 동작을 제공합니다. Esc 또는 Tab으로 마우스를 풀고 메뉴를 사용합니다. 창 이탈/숨김, 터치 취소 시 이동을 해제합니다. 모바일은 좌측 아날로그 조이스틱과 우측 터치 시점을 서로 다른 포인터로 관리합니다.

수술 건수와 진피 길이는 `dist/records.js`에 독립적인 필드로 보관합니다. 데모 합계는 가상 전문의 3명의 5,674건 및 2,980m이며 실제 병원 실적이 아닙니다. 랭킹은 수술 건수 기준으로 정렬합니다. 데모 순위는 김하늘(대한민국) 4,123건, Alex Kim(미국) 1,320건, Haruto Sato(일본) 231건입니다. 인증 표시는 국적에서 추론하지 않고 각 기록의 `verification` 필드로 제어하며, 현재 김하늘에만 데모 인증 배지를 표시합니다. 재료 체험만 **1건당 1장이라는 명시된 가정**을 사용하며, 체험 건수 2,000건 = 체험 진피 2,000장 = 120m입니다. 규격을 바꾸면 길이만 바뀌고 수술 건수나 전문의 기록은 바뀌지 않습니다. 실제 CRM을 연결할 때 수술 기록과 규격별 재료 사용 기록을 따로 집계해야 합니다.

길이(m) = 장수 × 선택 규격의 긴 변(cm) ÷ 100. 기본값 2,000장 × 6cm = 120m. 탑은 이 길이를 높이로 표현하며, 옆으로 보이는 폭과 대표 시트 수는 가독성을 위해 확대·축약했습니다. 적층 두께를 길이로 환산하지 않습니다. 에베레스트는 해발고도를 표시하는 개념 지형이며 실제 지형 데이터가 아닙니다.

5×6cm와 3mm는 사용자가 확인한 기준 규격입니다. 5×8·5×10·6×12cm는 추가로 제공된 규격입니다. 다른 규격의 3D는 기준 모델을 변형한 예시로 두께를 3mm로 유지하며, 실제 제품의 천공 형태와 두께를 나타내지는 않습니다. 구멍 패턴은 제공된 사진에서 추출했습니다. 사진의 원근·촬영 비율은 확인된 5:6 비율로 보정하며, 뒷면의 표면과 미세한 굽힘은 시각화용 근사입니다. 낙하는 강체 충돌 근사이며 생체 조직의 변형 해석은 아닙니다.

독립 브랜드 `admerest`의 제작자는 `by notoow`로 표기합니다. 회사 로고와 제휴 표기는 제거했습니다. 사용자가 제공한 2D notoow 원본은 웹과 OG 카드에, 3D 원본은 파비콘과 기기 아이콘에 사용합니다. 이 표기는 별도의 권리 귀속 합의를 대신하지 않습니다. 진피 사진은 사용자가 제공한 자료입니다.

## 파일

### 외부 건물 모델

4개 건물은 CC BY 4.0 자산입니다. 사이트 하단 **3D 모델 출처**에 원본 모델, 제작자, 라이선스와 변경 내역을 표시합니다. 원작자의 서비스 보증이나 제휴를 뜻하지 않습니다. 상세 출처와 SHA-256은 [`dist/assets/models/credits.json`](dist/assets/models/credits.json), Blender 재수입 검증은 [`models/landmark-validation.json`](models/landmark-validation.json)에 있습니다.

롯데월드타워는 Sketchfab 공식 GLB 다운로드, 나머지는 원작자 크레딧을 포함하는 [Smart UI 공개 데모](https://www.htmlelements.com/demos/3d-chart/custom-models/index.htm)의 배포본입니다. `scripts/optimize-landmarks.py`는 `qa/<id>-source.glb`를 Blender에서 읽어 변환합니다. 원본은 저장소에 중복 포함하지 않습니다. 에펠탑 모델의 외형은 제작 당시 표현이며, 비교 높이는 [현재 330m](https://www.toureiffel.paris/en/news/history-and-culture/300-330-meters-story-towers-height)로 맞춥니다.

### 구현 파일

- `dist/app.js`: UI, 상태, 계산, 입력 검증, 랭킹, WebMCP
- `dist/records.js`: 독립된 수술 건수·길이 기록, 합계, 수술 건수 랭킹
- `dist/scene.js`: 대체 랜드마크 모형, 조명과 환경 반사
- `dist/landmarks.js`, `dist/landmark-data.js`: 공유 GLB 로딩, 캐시, 재질, 랜드마크 높이
- `dist/explorer.js`: 3D 탐색, 비교 배치, 카메라, 체험 탑 성장
- `dist/flight.js`, `dist/flight-motion.js`: 키보드·터치 자유 이동과 시점 제어
- `dist/journey.js`, `dist/experience.css`: 스크롤 연출과 몰입형 탐색 화면
- `dist/atmosphere.js`: 하늘, 구름, 지면, 주변 지형
- `dist/assets/alpine-panorama.png`: Imagegen 환경 배경 ([프롬프트](models/alpine-art-direction.md))
- `dist/measurements.js`: 장수·길이 환산, 높이 비교, 대표 시트 배치 계산
- `dist/material.js`: 원본 사진 및 ADM 관통 형상
- `dist/physics.js`: 진피 낙하와 상세 보기
- `dist/styles.css`: 반응형 레이아웃
- `models/adm-sheet.blend`: 수정 가능한 Blender 원본과 스튜디오 조명
- `dist/assets/models/adm-sheet.glb`: 브라우저에서 실제로 사용하는 모델
- `scripts/model-adm.py`: 모델 수정 및 GLB 내보내기 재현 스크립트
- `scripts/trace-adm.py`: 원본 사진의 관통 형상 추출
- `scripts/bake-adm-material.py`: Blender 표면 노멀·거칠기 베이크
- `models/model-validation.json`: 원본 및 압축 GLB를 다시 불러와 검사한 결과

Blender 모델 재생성: `npm ci`, `node scripts/export-adm-mesh.mjs`를 실행한 다음 Blender 5.1의 `--background --factory-startup --python scripts/model-adm.py -- <프로젝트 절대 경로>` 옵션으로 실행합니다. 사진 패턴을 다시 추출하려면 먼저 `python scripts/trace-adm.py`를 실행합니다(Pillow, NumPy, OpenCV 필요). 수량·규격 계산은 모델의 두께에 영향을 받지 않습니다.

모델 검사: 두 모델 모두 닫힌 manifold이며 95개 관통부, Euler 특성 −188, 단면 두께 3.00mm를 검사합니다. 압축 GLB를 다시 불러온 후에도 모든 구멍과 단면 두께를 확인합니다. `npm run check`는 이 결과와 GitHub Pages의 상대 경로, 압축 해제 파일, JavaScript 문법, 길이 환산 및 대표 시트 배치 계산을 검사합니다.

검증: 데스크톱과 390×844 모바일 브라우저에서 수량/규격 변경, 잘못된 입력, 국적 필터, 배지 설명, 탑 이동 및 3D 렌더링을 확인했습니다. 데이터는 데모이므로 실제 인증 기능의 검증을 뜻하지 않습니다.

이동 계산 검사는 카메라 방향에 따른 이동, Q/E의 독립 수직 축, 대각선 속도 정규화, 반대 키 상쇄, 지면 및 환경 경계를 포함합니다. 스크롤 배경은 장식용 생성 이미지이며 실제 지형 측량 데이터가 아닙니다. 3D 설산도 해발고도에 맞춘 개념 지형입니다.

랜드마크 참고: [롯데월드타워](https://www.lottecon.co.kr/Medias/tower_intro_stability), [부르즈 칼리파](https://www.burjkhalifa.ae/img/fact-sheet.pdf). 라이브러리 라이선스는 `dist/vendor/`에 포함되어 있습니다.


## ADM 노트

- 메인 하단과 상단 메뉴에서 `notes.html`로 연결됩니다. 별도 3D 로딩 없이 읽을 수 있는 정적 페이지입니다.
- 6가지 질문은 재료의 정의, 규격, 흡수·장기 근거, 천공, 합병증, 수술 기록 해석을 다룹니다. 원문 지침·논문·제품 설명을 각 글과 출처 목록에 연결했습니다. 상단 논문 수는 중복을 제외한 학술논문 6편이며, 지침·제품 설명·영상은 논문 수에 포함하지 않습니다. 의료진 감수 완료로 표기하지 않습니다.
- 규격은 제공된 5×6·5×8·5×10·6×12cm를 사용합니다. 노트의 단일 비교 카드 안에서 네 규격을 항상 함께 표시하며, 아이폰 16·칫솔·카드를 바꾸면 전체 규격의 비율이 함께 갱신됩니다. 규격 클릭은 해당 진피와 표의 열만 강조하고 다른 규격을 숨기지 않습니다. 기본 물건은 카드이며 치수는 ISO/IEC 7810 ID-1의 85.60×53.98mm입니다. 아이폰 본체 치수 7.16×14.76cm는 Apple 공식 규격이며, 칫솔 1.5×19cm는 비교용 예시입니다. 두 축에 같은 배율을 적용하며 1,000장 길이는 60·80·100·120m입니다. 메인 3D의 다른 규격은 기존 기준 모델을 변형한 예시임을 명시합니다.
- 기본 ‘실물 크기’ 보기에서는 96 CSS px/in의 초기값을 사용하고 화면 폭에 맞춰 물건을 축소하지 않습니다. 크롬 100%에서도 실제 모니터의 물리적 밀도는 알 수 없으므로, 실제 카드와 테두리를 맞추는 50–250% 보정(0.1% 단위)을 제공합니다. 카드와 네 진피 모두 동일한 보정값을 사용합니다. ‘이 크기로 저장’을 누르면 이 브라우저에만 저장하고 같은 화면 크기·devicePixelRatio에서 복원합니다. 환경이 달라지면 다시 확인하도록 안내하며, 같은 해상도의 다른 모니터까지 식별하지는 못합니다. ‘한눈에 보기’는 기존 전체 도식을 반응형으로 축소합니다. [CSS 화면 단위 설명](https://www.w3.org/Style/Examples/007/units.en.html)
- 하이스트 비뇨의학과 영상 4편은 클릭하면 전용 보기 창에서 재생합니다. 일반 영상은 가로, Shorts는 세로 비율로 크게 표시합니다. 클릭할 때만 `youtube-nocookie.com/embed/` iframe과 YouTube IFrame API를 로드하고, 종료 시 iframe을 제거한 뒤 다시 보기·다음 영상 화면을 제공합니다. 전환·닫기 시 이전 플레이어를 제거하고 닫으면 원래 카드로 포커스를 돌려줍니다. API가 차단돼도 기본 iframe과 YouTube 원본 링크를 사용할 수 있습니다. 공개 썸네일은 YouTube 이미지 서버에서 불러옵니다.
- YouTube 자체 컨트롤과 전체화면을 유지합니다. `rel=0`은 추천을 같은 채널로 제한할 뿐 일시정지 추천 UI를 완전히 제거하지 않습니다. 플레이어를 가리는 별도 덮개를 씌우지 않습니다. [공식 매개변수 문서](https://developers.google.com/youtube/player_parameters#rel)
- `strict-origin-when-cross-origin` referrer 정책을 유지합니다. 동영상별 로그인·외부 재생 제한은 YouTube 정책을 따르며 항상 원본 링크를 함께 제공합니다.
- 영상 설명은 채널의 견해이고, 학회 지침 및 논문 근거와 구분합니다. 브랜드 제작자 표기는 notoow, 영상 출처만 하이스트입니다.

- 하이스트의 동종진피 전용 사용, 수화·건조 타입별 다양한 규격, 두께 3–5mm는 운영자 제공 정보로 표시합니다. 타입별 SKU 조합은 추정하지 않으며 3D 모델의 3mm와 실제 재료의 두께 범위를 구분합니다. 피부의 인체조직 기증과 미용 목적 동의 범위는 보건복지부 및 캘리포니아 공식 법령을 연결해 설명하고, 특정 국가의 절차를 국내 모든 제품에 일반화하지 않습니다. 동종/이종의 포괄적 우월성 대신 수술별 근거를 설명하고, 이종진피의 유방 재건·화상 피복 사용 연구를 출처와 함께 연결합니다.

자동회전은 실제 프레임 경과 시간을 OrbitControls에 전달하고, 라벨 크기는 ResizeObserver로 캐시해 프레임마다 레이아웃을 강제하지 않습니다. 겹침으로 인한 라벨 이동은 시간 기반으로 보간하며 캔버스 경계 안에 배치합니다. 정적인 탐색 장면의 그림자는 카메라 회전 중 재사용하고, 모델 로딩·배치·표시·체험 탑 변화 시 갱신합니다. `get_admerest_state`의 `rendering`에서 최근 120프레임 간격과 렌더링 비용을 진단할 수 있습니다.

천공 설명은 재혈관화 동물실험(PMID 30730495)과 절개 패턴의 액체 배출 실험(PMID 33728235)을 연결합니다. 운영자가 전한 수술 1–2년 후 절개 시 출혈 설명은 별도로 출처를 표시하며, 출혈만으로 완전 생착·원래 피부와 동일한 기능을 단정하거나 1–2년을 보편적인 생착 기간으로 설명하지 않습니다.

## 인증과 공개 범위

`isTowerPublished`가 공개 3D 탑의 기준을 정합니다. 인증 완료(`verified`) 또는 데모 인증(`demo`) 기록만 3D 공간·전문의 탑 목록·비교 선택지·탑 이동 도구에 포함합니다. 미인증 기록은 랭킹에 남고 ‘미인증 · 랭킹만 표시’로 구분합니다. 현재 김하늘만 데모 공개 탑이며, 총 수술 케이스와 진피 길이 합계는 랭킹의 세 기록을 계속 합산합니다. 인증 안내와 툴팁은 자격·객관 기록 확인 후 공개되는 흐름을 설명합니다. 실제 가입, 서류 제출, 서버 심사는 구현되지 않은 데모입니다.

## ADM STACK 미니게임

`game.html`은 기존 천공 진피 GLB를 눕혀 쌓는 별도 게임입니다. 좌우에서 번갈아 움직이는 진피를 Space, 클릭, 터치로 놓습니다. 0.18 cm 이내 정렬은 퍼펙트로 중앙에 맞추며, 나머지는 어긋난 위치 그대로 쌓습니다. 각 접촉면 위에 있는 같은 무게 시트들의 합성 무게중심이 실제 겹친 지지 구간을 벗어나면 무너집니다. 접촉이 없으면 놓친 것으로 끝납니다. 이는 게임용 강체 근사로, 임상적인 진피 변형·생착 모델이 아닙니다.

50장 완주, 퍼펙트 연속 표시, 균형 게이지, 다시 시작, P/Esc 일시정지 및 화면 이탈 자동 일시정지를 제공합니다. 최고 기록만 로컬 저장하며 서버·전문의 랭킹에 전송하지 않습니다. 5×6 cm / 3 mm 모형의 쌓인 두께(50장 = 15 cm)를 표시합니다. `stack-rules.js`의 순수 규칙은 정렬·실패·무게중심·일시정지를 테스트하며 WebMCP의 `get_stack_game_state` / `control_stack_game`는 같은 UI 동작을 노출합니다.

## 모바일 탐험과 기록 연출

모바일은 DPR 1.2 상한과 그림자 생략을 적용하고, 느린 프레임이 지속될 때만 해상도를 단계적으로 낮춥니다. 탐험 또는 기록 연출 중 다른 두 WebGL 장면은 렌더링·물리 계산을 멈춥니다. 겹친 바닥·격자·그림자 면을 제거해 깊이 버퍼 충돌을 없앴습니다. 먼 진피는 같은 사진과 95개 천공을 쓰는 5,724삼각형 모델, 가까운 탑은 기존 Blender 모델을 사용합니다. 상세 보기 모델은 유지합니다.

시점 입력은 프레임에서 시간 기준으로 보간하며, 조이스틱 영역은 터치 시작 시에만 측정합니다. 손을 떼거나 창이 비활성화되거나 화면 방향이 바뀌면 이동을 해제합니다. 주소창 접힘처럼 뷰포트 높이만 바뀔 때는 조이스틱 입력을 유지하고 시점 좌표만 다시 잡습니다. 이동과 시점의 독립 터치, 30/60/120fps 시점 보간, 프레임 밖 중복 키 이동 방지, 다른 장면 중단을 테스트합니다. 모바일 뷰포트 검증은 실제 iOS/Android GPU 성능 측정과는 별개입니다.

박스는 한 장·8장·40장을 떨어뜨리는 자유 놀이터입니다. 실제로 생성한 낙하 장수를 표시하고, 수술 건수 계산·랭킹에는 반영하지 않습니다. 지속해서 부으면 오래된 시트는 밖으로 밀려나 떨어집니다. 랭킹의 공개 프로필에 있는 ‘기록의 순간’은 한 장 → 소나기 → 대표 시트 탑으로 이어지는 6.4초 연출입니다. 수술 건수와 진피 길이는 독립된 기록으로 정확히 마무리하며, 떨어지는 모델 개수가 실제 사용 장수라는 뜻은 아닙니다. 같은 WebGL 캔버스를 재사용하고 닫기·Esc·건너뛰기·재생·탑 복귀를 지원합니다. 동작 줄이기 설정에서는 최종 장면으로 바로 이동합니다. 현재는 데모 기록 감상 기능이며 가입·인증 서버 동작을 추가하지 않습니다.

도시와 나무는 인스턴싱한 장식 배경입니다. 에펠탑 주변의 주황 구슬을 누르거나 탐험 중 가까이 가서 발견 버튼을 누르면 노을이 열립니다.

## 내 기록 미리보기

메인의 전문의 목록과 랭킹에서 `record.html`로 이동합니다. 표시 이름·소속·국적·수술 건수 → 규격별 사용 장수 → 탑 비교와 기록 연출의 세 단계입니다. 5×6·5×8·5×10·6×12cm의 수화/건조 타입을 한 표에 입력합니다. 수술 건수는 별도 입력값이며, 길이는 여덟 칸의 장수 × 각 규격의 긴 변을 정수 cm로 합산한 뒤 m로 환산합니다. 사용 장수를 수술 건수에서 추정하지 않습니다.

공개 예시 3명과의 비교 순서를 보여주되 실제 랭킹은 수정하지 않습니다. 입력 기록은 항상 `preview: true`, `verification: 'none'`이며 비공개 미리보기임을 표시합니다. 서류 제출·공개 등록·심사는 아직 연결하지 않았습니다. ‘이 기기에 초안 저장’을 눌렀을 때만 버전이 있는 localStorage 초안을 저장하며, 삭제 전 확인을 제공합니다. 저장 차단 시에도 입력과 미리보기는 가능합니다. 이름 등 사용자 입력은 HTML로 삽입하지 않고 textContent로 표시합니다.

3D 코드는 마지막 단계에만 로드하고 같은 캔버스를 랜드마크 비교와 낙하 연출에 재사용합니다. 정적인 탑 비교에서는 그림자를 캐시하고, 동적인 기록 연출 동안만 그림자를 다시 계산합니다. 연출 완료 수치는 소수점 길이까지 보존합니다. 네 랜드마크 선택과 회전·확대·시점 초기화를 지원합니다.

`draft-record.js`는 입력 검증·합산·저장 형식, `record.js`는 단계·저장 UI, `draft-preview.js`는 전용 3D 미리보기입니다. 읽기 전용 WebMCP `get_record_draft_state`는 단계·합계·비공개 상태만 반환하며 이름과 소속은 반환하지 않습니다. `npm run check`의 36개 검사는 혼합 규격 합산, 잘못된 숫자, 상한, 인증 필드 제거, 카드 보정·화면 환경별 복원과 기존 동작을 포함합니다. 브라우저에서 저장·복원·삭제 취소, 모바일 표, 소수점 연출과 탑 복귀를 확인했습니다.

## 사용 흐름 점검

영상은 320×568·390×844 세로 화면, 844×390 가로 화면, 1440×1000 데스크톱에서 확인했습니다. Shorts의 실제 재생 종료, 다음 영상 전환, 닫기 후 iframe 제거와 포커스 복귀를 확인했습니다. 자동 검사는 API 로딩 중 닫기, 늦게 도착한 이전 영상 이벤트, 재생 완료·다시 보기, API 실패 시 기본 플레이어 유지를 다룹니다.

탑 선택 후 입력 패널이 열리거나 화면 폭이 바뀌어도 선택한 탑의 카메라를 유지합니다. 전체 보기에서는 입력 패널을 접습니다. 카메라 리사이즈 회귀 검사를 포함하며, 국적 필터·배지 안내·수량/규격 입력·비교·탐험 조작·기록 연출·게임 시작/놓기/실패/재시작/일시정지를 브라우저에서 점검했습니다. 박스에 8+1+40장을 추가했을 때 실제 생성 수 49장과 비우기를 확인했습니다. 모바일 조작 검사는 데스크톱 브라우저의 모바일 뷰포트와 포인터 입력 기준이며 실제 휴대폰의 GPU·멀티터치 성능 측정은 아닙니다.

## 체험 진입과 터치 조작

`직접 체험하기`를 첫 화면과 탑 탐색 툴바에 크게 표시합니다. 버튼이 보일 때 바깥 고리가 3.6초 간격으로 네 번 퍼지고, 한 번 진입하면 해당 페이지에서 더 이상 펄스하지 않습니다. 동작 줄이기 환경에서는 정적인 테두리만 표시합니다.

모바일은 별도 `flight-look-pad`에서 시점 드래그를 처리하며, 조이스틱·시점·상승 버튼은 각각 다른 포인터를 추적합니다. 취소/종료 시 조이스틱과 시점 포인터 캡처를 해제하고, 조이스틱 주변 16px까지 터치 영역을 넓혔습니다. 화면 회전 시에는 모든 입력을 안전하게 해제합니다. 여러 손가락의 동시 입력 이벤트는 컨트롤 회귀 테스트로, UI는 320×568·390×844·844×390에서 확인합니다. 실제 휴대폰의 멀티터치·GPU 성능 검증은 별도로 필요합니다.
